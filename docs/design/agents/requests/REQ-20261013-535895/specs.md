# 范围与验收

- LOCAL：本机初始化、原生认证、同源代理与 WebSocket、拒绝公共备份仓库、每日调度参数。
- FILES：文件字节、隐藏文件、Git 元数据、模式和内部链接可恢复；缺块、错误密钥、越界路径不能写入恢复目标。
- PG：完整 PG 数据、序列、关系、联合频道关联、角色和 ACL，以及应用密钥可恢复。
- APP：真实用户与 Agent 头像、聊天附件、Agent 配置、登录和 MCP 密文解密；恢复重建 RW 并可重启。
- COMPUTER：真实 Computer 停止、原 managed 集合恢复、新目录工作文件恢复及重新连接。
- GITHUB：仅向已授权私有库上传合成数据加密快照，下载后逐文件哈希一致。

所有已登记文件根完整保存；只排除 Computer 的进程/IPC 目录。官方云迁移、第三方托管文件、系统钥匙串、内存执行现场和未登记目录不包含。调度生成后由使用者启用，不擅自配置个人服务。
